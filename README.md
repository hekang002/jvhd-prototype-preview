# 今晚喝点吗 · 可交互产品原型

> JVHD · 反差型少喝微信小程序（外表劲浪，内核清醒）
> 纯前端 HTML 原型：无后端、无依赖、无构建。双击 `index.html` 即可运行，也可以放在任意静态服务器上。

---

## 一、怎么打开

1. 双击 **`index.html`**（推荐 Chrome / Edge / Safari 最新版）。
2. 启动页会看到两张卡片：**「小程序原型」** 与 **「后台原型」**，点哪张进哪个端。
3. 两端共用同一份浏览器本地数据（localStorage），可以在两个标签页里同时打开，一边在后台审核、一边在小程序里看到结果。

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| 启动页 | `index.html` | 选择进入哪一端 |
| 小程序 | `mini/index.html` | 左边是演示导航与「演示场景」，中间是 iPhone 手机壳 |
| 后台 | `admin/index.html` | 账号密码登录后进入运营控制台 |

**注意**：用 `file://` 直接双击打开也能跑；如果浏览器对本地文件限制较严（个别版本的 Safari / Firefox），在本目录执行
`python3 -m http.server 8787`，然后访问 <http://127.0.0.1:8787/index.html>。

### 后台演示账号（密码统一 `jvhd@2026`）

| 账号 | 角色 | 能看到什么 |
| --- | --- | --- |
| `hekang` | 超级管理员 | 全部 11 个模块，可改阈值、管角色、看操作日志 |
| `linxiao` | 运营 | 酒库/文案/无醇/提醒/地图/合规；**阈值、角色、日志菜单置灰**，点按被拦截 |
| `zhouchang` | 合规审核 | 文案审核、提醒审核、合规中心、操作日志；导出原始数据被拒 |

运营账号的目的：演示「最小权限 + 越权留痕」——点灰掉的菜单会弹出「当前角色无权访问该模块」，在「操作日志」里能看到一条被拒绝记录；在用户详情里点「导出个人数据」会触发 NFR-05 拦截弹窗。

### 重置数据

- 启动页底部「重置全部演示数据」；
- 小程序舞台左侧「演示场景 → 新用户」；
- 后台右上角帮助「原型说明」、或直接清空浏览器 localStorage。

## 二、小程序原型（`mini/`）

手机壳尺寸 390×844，模拟真机滚动与微信标题栏。左侧字幕式说明会随页面更新。

### 底部五个 Tab

| Tab | 关键交互 |
| --- | --- |
| **今晚**（首页） | 三选一决策：`喝` → 30 秒记录；`不喝` → 直接写「不喝」并给反馈卡；`再想想` → 启动 **10 分钟拖延冷却**，首页顶部出现倒计时条（×60 加速可 10 秒结束），到点自动重新询问。首页数据摘要：今日酒精量、无酒连击、本月省下金额 |
| **酒局日历** | 月视图：**无酒日留白**、有酒日按克数 4 档灰阶（≤10g / 10–25g / 25–60g / >60g）、**超量日细红边**、记录过「不喝」的日期带圆点。点某天 → 日明细 → 可补录 / 修改当日总量（按比例缩放每条记录） |
| **克制地图** | 7 个地点的私人地图：去过 1 次正常、≥3 次泛灰、≥5 次标「老地方」、≥10 次空心点；点亮起地点卡片，配中性评语（「老地方，老朋友，老毛病。」「来过 4 次了。」），可生成**脱敏分享卡**（只到城市级） |
| **小游戏** | 骰子·劝退局（最高免饮、最低换无醇，没有惩罚规则）／酒精代谢推算（体重、酒精度、时间滑块实时算 BrAC·BAC）／今晚能不能喝抽卡／一杯倒计时 |
| **我的** | 数据摘要（省下¥、奶茶杯数）、无酒连击与复活券、数据导出（真实下载 JSON）、隐私设置、注销账号 |

### 记录页（FR-2-01 / FR-2-03）

- 7 类酒（啤酒/葡萄酒/黄酒/白酒/洋酒/鸡尾酒/其他）+ 自定义；
- 数量加减 + 常用预设，**酒精克数实时换算**：`ml × %vol ÷ 100 × 0.789`；
- 酒库抽屉：搜索 2318 条酒库、可选酒款、可改酒精度/容量；
- 地点、场景、心情均为选填，**提交后**自动写日志、累加地点次数、写决策事件，跳到「结果页」并轮换 3 选 1 反馈卡。

### 结果页

按 少喝% / 省下金额 / 省下热量（奶茶杯数）轮换展示，可再抽一张；`生成分享图` 弹出脱敏分享卡；`再记一杯` 回到记录页。

### 年龄门与青年模式（合规）

首次进入先过年龄门。「我未满 18 周岁」→ 青年模式：

- 底部只剩「今晚 / 酒局日历 / 我的」，**地图与游戏菜单消失**，直接访问 `#/map`、`#/game` 显示拦截页；
- 首页隐藏「喝」入口，只保留「不喝」与「再想想」，并常驻合规提示条；
- 记录页被拦截，不再出现任何酒类内容。

### 演示场景（舞台左侧按钮）

| 场景 | 作用 |
| --- | --- |
| 记录一杯 | 跳记录页，演示 30 秒录入 |
| 再想想 | 立即触发拖延冷却倒计时 |
| 加速演示 ×60 | 冷却按 10 秒推进，方便看「到点重新询问」 |
| 新用户 | 清空为空白数据，从年龄门开始走一遍首次使用 |

## 三、后台原型（`admin/`）

### 11 个模块

| 模块 | 演示要点 |
| --- | --- |
| 运营看板 | 4 个核心 KPI + 趋势折线（日活/记录率/不喝占比切换）+ 三选一决策环图 + 决策漏斗 + 延迟后行为 + 克制成果 + 待办 |
| 用户管理 | 12,486 注册用户、青年模式用户标记、搜索分页；点「详情」打开抽屉：**脱敏视图**（只有城市级地点）、近 60 天饮酒折线、记录明细、操作流水；导出需二次验证，删除需确认 |
| 酒库管理 | 约 2000+ SKU；页签「全部 / 待审核 / 已上线 / 用户自定义」；**通过后即时上线并同步到小程序酒库**（NFR-09 免发版）；驳回需选原因；批量导入 |
| 文案库 | 12 条文案（按 F1–F6 场景分类）；右侧合规词库 6 个禁用词。点编辑 → 改内容含「干了」→ **实时标红命中禁用词，发布被拦截** |
| 无醇替代 | 7 条替代方案按酒类分组、上下线、效果统计（点击次数 / 真实改喝率 / 折算少喝酒精） |
| 阈值与规则 | 12 项配置可改（日阈值、标准杯、冷却时长、静默时段、单杯均价…）；前 4 项为**合规强制项，开关锁死不可关**；保存需二次确认并写入变更记录 |
| 提醒与推送 | 订阅消息模板上下线/试推送；22:00–08:00 **静默时段强制拦截**（试推送会提示被拦截并记录）；新建提醒（标题/时段/每周频控 ≤3） |
| 地点聚合 | 城市级气泡热力图 + Top6 商圈；数据请求合规检查（否则拒绝下发） |
| 合规中心 | 6 项自检清单全部通过；高风险文案列表；数据导出请求队列 |
| 角色权限 | 4 个角色卡 + 权限矩阵（✓ 可操作 / — 无权限）；子账号管理 |
| 操作日志 | 428 条留痕，支持「全部 / 成功 / 被拒绝 / 被拦截」筛选和导出；被拒绝与越权请求都在这里 |

### 建议走一遍的联动链路

1. 后台登录 `hekang` → 酒库管理 → 待审核页签 → 点某条「通过」；
2. 另开标签页进入小程序 → 首页点「喝」→ 记录页点「选择酒款」→ 搜索刚才通过的那款酒，**已经在酒库里了**；
3. 回到后台换成 `linxiao` 登录 → 左侧「阈值与规则 / 角色权限 / 操作日志」变灰 → 点一下 → 弹出无权提示 → 再用 `hekang` 看「操作日志」，能找到这次被拒绝的请求；
4. 后台文案库改一条文案写入「干了」→ 发布被拦截；阈值页把「单杯均价」改成 60 → 小程序「我的」里省下金额随之变化。

## 四、口径与规则（和需求文档一致）

| 项目 | 规则 |
| --- | --- |
| 酒精克数 | `ml × %vol ÷ 100 × 0.789` |
| 标准杯 | 克数 ÷ 10 |
| 单日超量线 | 男 60 g / 女 40 g |
| 膳食指南参考 | 男 25 g / 女 15 g |
| 本月少喝% | (近 3 月月均基准 − 本月) ÷ 基准 |
| 省下金额 | 少喝克数 ÷ 10 × 单杯均价（默认 ¥45） |
| 省下热量 | 每克酒精 7 kcal，650 kcal ≈ 1 杯奶茶 |
| 无酒连击 | 最近一次饮酒的次日起，连续无酒天数 |
| 复活券 | 每月 1 张，诚实补记不清零连击 |
| 代谢推算 | BrAC(mg/L) ≈ g ÷ (体重 × r) × 1000，r 男 0.68 / 女 0.55；BAC ‰ ≈ BrAC × 2.1；代谢 10 g/h |
| 拖延冷却 | 10 分钟，可加速演示；冷却中「再想想」不可重复点，可「提前去喝」 |
| 克制地图 | 次数越多越灰：≥3 泛灰、≥5「老地方」、≥10 空心；评语中性，不打分不排名 |
| 合规红线 | 不卖酒、无购酒链接/价格/广告；禁「干了 / 不醉不归 / 拼酒 / 罚酒 / 斗酒 / 感情深」；22:00–08:00 禁推、每周 ≤3 次；位置单独授权、仅本人可见、分享脱敏到城市级；精确坐标 12 个月降级 |

## 五、文件结构

```
prototype/
├── index.html          启动页：选择「小程序原型 / 后台原型」
├── README.md           本说明
├── css/
│   ├── common.css      设计令牌、Toast、弹窗、启动页
│   ├── mini.css        小程序端（暗色酒单风）
│   └── admin.css       后台端（浅色墨绿）
├── js/
│   ├── core.js         日期/换算/激励计算/图标/Toast/弹窗/路由

├── mini/
│   ├── index.html      手机壳舞台
│   └── app.js          小程序页面与交互
└── admin/
    ├── index.html      后台外壳
```

> 数据全部在浏览器 localStorage（键前缀 `jvhd_proto_`），不上传任何服务器；清除站点数据即恢复初始演示数据。

## 六、已知边界

- 分享图、数据导出为前端模拟（导出会真实下载 JSON / CSV 文件，分享图为页面内卡片，不生成图片文件）；
- 手机壳内的「微信导航栏」会遮盖滚动内容（真机效果），页面内容从标题栏下方开始；
- 酒库总数、用户量等为设计用演示数据；
- 桌面端体验最佳（小程序为固定手机壳）；窗口 < 1100px 时会自适应但布局会压缩。
